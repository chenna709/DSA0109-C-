# Task 6 – Design challenge: vehicle rental fleet

## Hierarchy
`Vehicle` is abstract. `Bicycle` and `MotorVehicle` derive publicly from it. `TwoWheeler`, `Car`, and `ElectricCar` derive from `MotorVehicle`; `ElectricBus` is an extension.

## Demonstration
The program creates a rental fleet, rents and returns vehicles, and demonstrates polymorphic charges.
